## 実演(全部この場で走らせた)
### (a) ずれを検出できる
friday の `health-step.mjs` に1行足す(= 判定の本体だけを古くする。今までの3本構成では
**見えなかった**種類のずれ):
  NG tools/health-step.mjs — ずれている(repo=fe4b5d7c… friday=bf7f2de1…)  他4本は ok / exit 1

### (b) 端から端まで直せる
  1 ずれ検出 → 2 退避(5本) → 3 配布 → 4 独立の再測定 5/5 一致 → 5 自己検査
  SELFTEST_RC:0 / SELFTEST_NONCE:yes → 完了 rc=0

### (c) 自己検査が**赤を出せる**(此処が要)
配備物を `#!/bin/bash\nexit 0` の偽物に差し替えて自己検査だけを直接撃つ:
  SELFTEST_RC:0            ← **exit code だけを見る検査は此処で通っていた**
  SELFTEST_NONCE:no ← ★赤 = 偽物を掴んだ
本番は復元し、parity 5/5 を再確認。

### (d) 一致している時は配らない
  「既に一致している。配らない(無駄な再起動を起こさない)」 exit 0

### (e) rollback が実際に働く
自己検査が落ちた回(下記の私のバグ)で自動発火し、退避から戻した上で
「※戻した結果はまだ repo とずれている(= 配る前の状態に戻った)」と正直に報告した。

## ★書いていて自分で踏んだ欠陥3件(記録として残す)
1. `scp` の宛先で `$HOME` が展開されない(`ssh` と違い sftp のパス扱い)。
   → 実 path を先に `ssh` で引く。
2. **二重引用符の中のバッククォートが手元の shell でコマンド置換される**。
   remote へ渡す文字列の註に `RC_HEALTH_HOST` をバッククォートで括り、
   `RC_HEALTH_HOST: command not found` が出た。remote の話に見えるが手元の事故。
   ★**同じ日に2回踏んだ** —— 1回目を説明する註を、同じ文字列の中に書いて再演した。
   → 註は remote 文字列の**外**に置く規約にした。
3. 原因の切り分けでも1回外した: 症状が env 代入の行に出たので「行継続の欠落」と推測して
   書き換えたが直らなかった。**症状の出る場所は原因の場所とは限らない。**
4. nonce を `RC_HEALTH_HOST` で渡してログに現れる事を期待したが、**実測したら observer は
   健全時に HOST を1行も書かなかった**。期待で組んだ印は印にならない。
   → 隔離した一時ログの中身そのものを印にした(launchd の定時実行とも混ざらない)。
