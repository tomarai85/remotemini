## What the endpoint is
`ota-server.mjs`: a ~120-line Node HTTP server on an always-on Mac mini, bound to 127.0.0.1:8788, GET/HEAD only, no directory listing. `tailscale serve` exposes it at `https://<host>:9443/ota` on a tailnet (Funnel can only use 443/8443/10000, so this path is structurally not publicly reachable). It serves an iOS Ad Hoc `.ipa` + `manifest.plist` so the owner's iPhone can install a build over the air.

**It has no authentication and cannot have any**: iOS `installd` fetches the manifest and the ipa without sending custom headers. The only access control is an unguessable 24-hex path segment, plus `chmod 700` on the directory (a same-machine leak through group-readable perms was found and fixed 2026-08-28 — there are three human accounts on this box).

## The change
It previously logged NOTHING per request, so "tapped but the install failed" and "never tapped" were indistinguishable. Added one line per request:

```js

export function otaPathShape(urlPath) {
  const clean = String(urlPath || "/").split("?")[0];
  return clean.split("/").map((seg) => (SECRET_SEG.test(seg) ? ":secret" : seg)).join("/");
}

export function otaClientClass(userAgent) {
  const ua = String(userAgent || "");
  if (!ua) return "none";
  if (/^rc-live-/i.test(ua)) return "probe";
  if (/CFNetwork|Darwin/i.test(ua)) return "app";
  if (/curl|wget|node|undici|python|libwww/i.test(ua)) return "tool";

function logReq(req, code, bytes) {
  process.stdout.write(
    `[ota] req ${new Date().toISOString()} ${req.method} ${otaPathShape(req.url)} `
    + `client=${otaClientClass(req.headers["user-agent"])} code=${code} bytes=${bytes}\n`,
  );
}
```

Wiring: every early return goes through `done(code, body)` which now calls `logReq(req, code, Buffer.byteLength(body))`. HEAD logs 200/0.

stdout goes to a launchd-redirected file owned by the service account.

   `/%61bc.../manifest.plist` や `/<secret>%2Fmanifest.plist` は、配信側では decode されて正規ファイルへ到達しますが、logger は生 URL を見るため secret を残します。`;x`、secret を埋め込んだ filename、absolute-form も漏れます。「文字種を問わず N 文字以上」でも直りません。固定語彙で `/:secret/:ipa`、未知形はすべて `/:other` が正解です。現行ファイルは既にこの方式へ変更されています。[ota-server.mjs](/Users/tomtim/Infra/mobile-work/rc-backend/tools/ota-server.mjs:79)

2. **無制限ログはノイズではなく可用性欠陥。**  
   secret 不要の 404 spam だけで共有ディスクを埋められます。さらに POSIX で通常ファイルへ向く stdout は同期書き込みなので、遅いディスクでは Node 全体を止めます。[Node process I/O](https://nodejs.org/api/process.html)  
   必須なのは「容量上限付き retention」と、`/:other` 404 の sampling/drop。rename だけの rotation は、稼働中プロセスが古い fd を握り続けるので不十分です。書き込み失敗も非致命化してください。

3. **`close` は使えるが、計測値の意味が強すぎる。**
