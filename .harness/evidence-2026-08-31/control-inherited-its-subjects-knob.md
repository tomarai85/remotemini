# 対照が「測る相手の摘み」を走らせる側から継いでいた —— 30 分の沈黙の正体(2026-08-31)

## 症状

全掃き(120 本)が 09:12:59 から 09:42:59 まで**台帳を 1 行も進めずに止まって見えた**。
単独で叩くと `ios/tools/xcode-tree-lock-controls.sh` は 48/48 緑。

## 追った順序(外した仮説も残す)

1. **外した仮説**: `ps` の親子が
   ```
   40521 run-controls.sh
    └ 87434 run-controls.sh          ← 「掃引が自分自身を起動している」と読んだ
       └ 87442 xcode-tree-lock-controls.sh
   ```
   に見えたので「対照が全掃きを入れ子で回している設計欠陥」と判断した。**誤り**。
   bash の**部分shell は `ps` に親と同じ argv を出す**。87434 は fork された部分shell で、
   新しい起動ではない。`lsof -d cwd` で両者の cwd が本物の repo だと確かめた時点で
   「砂場でなく本物の木で回っている」まで判ったが、そこから先の読みが `ps` の見た目に
   引っ張られていた。★**プロセスの同一性を argv で判断しない。**

2. 詰まっている葉を辿ると `xcode-tree-lock.sh acquire B` で、その子は `sleep 5`。
   = 待ち続けている。待ちは `RC_XCODE_TREE_LOCK_WAIT_S` が支配する。

3. 走らせる側を読むと `run-controls.sh` に
   `export RC_XCODE_TREE_LOCK_WAIT_S="${...:-1800}"` が在り、**全ての子へ輸出**していた。
   対照側の `run()` は `RC_XCODE_TREE_LOCK` と `MAX_S` を固定するが `WAIT_S` を固定しない。

## 機構

`L2`(「握られている間、2 本目は**非零で降りる**」)は、待ちの既定が 0 である事に乗っている。
掃引の中では継いだ 1800 が効くので、L2 は降りずに **1800 秒 待つ**。
掃引側の 1 本あたりの帽子も 1800 秒なので、この対照は毎回 帽子で切られて `rc=2`
(測っていない)になる —— **一度も判定を出さないまま 30 分を焼く**。

単独では既定 0 なので 48/48 緑。だから「単体では緑、掃引でだけ死ぬ」に見えた。

## 実測(同じ機械・同じ瞬間・同じ台本)

| 環境 | 結果 |
|---|---|
| `WAIT_S=1800`(掃引と同じ) | L1/L1b の 2 本で停止 → 75 秒で打ち切り |
| `WAIT_S=0`(素の既定) | PASS 48 / FAIL 0 |
| 直した後に `WAIT_S=1800` | rc=0 / PASS 48 / FAIL 0 |

## 直し方

対照の冒頭で `export RC_XCODE_TREE_LOCK_WAIT_S=0` を**自分で立てる**。
待ちが要る 2 件(W1/W2)は各自が命令行で立てるので潰されない。

加えて `L2-pre` を足した —— 冒頭の export が消えると、また 30 分 黙る事になる。
黙る代わりに**即座に赤くして理由を名指しする**。実測: export を外した版は rc=1 で即停止。

## ★一般化(之が持ち帰る物)

> **X の対照は、X の摘みを X の走らせ手から継いではいけない。**

継ぐと「対照が測っている物」が走らせ方で変わる。単体緑 / 束で死ぬ、という
最も読みにくい形で出る。今朝 `tunnel-observer.sh --report` で踏んだ argv の乗っ取り
(source した file の中の `$1` が呼び手の `$1` だった)と同じ族 ——
**外から入る値が中の意味を書き換える**。

同じ掃引で見つかった同族が 2 件:

- `run-controls-ledger-controls.sh` の R8 が**本番の台帳へ偽の判定を書いていた**。
  「台帳を差さずに走らせる」を本物の木の中でやると、既定は本番の台帳になる。
  `r-controls.sh rc=1` という**存在しない対照の赤**が本番に載った(120 本の筈が 123 行)。
- `run-controls.sh` の「一覧を差した時は登録の照合を飛ばす」が、門が空の時の `exit 2` より
  **後ろ**に在った。実物の木では門が必ず埋まるので露見しない。砂場に走者だけを複製した
  瞬間に「何も走らせず集計行だけ刷る」形で出た。

3 件とも「**実物の木では常に成り立つ前提**に、黙って寄り掛かっていた」。
