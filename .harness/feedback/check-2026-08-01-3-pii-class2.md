## hook の配線 — 初めて発火を観測した

`.git/hooks/pre-push` は書いてあっただけで、**止めた所も通した所も一度も見ていなかった**。
使い捨ての bare repo を相手に両方向を測った(remote は測定後に撤去済み、`git remote` は空)。

| 向き | 結果 |
|---|---|
| 赤の repo(この repo)から push | **拒否**。`error: failed to push some refs` / bare 側の ref は **0本**(転送前に止まった) |
| 綺麗な木 + 同じ hook から push | **成功**。`refs/heads/main` が bare 側に出来た |

常に止める道具でも、常に通す道具でもない事を観測で確定した。
