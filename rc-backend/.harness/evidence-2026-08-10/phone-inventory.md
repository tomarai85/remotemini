# 電話の在庫の照合(鎖⑧の追加)— 2026-08-10 の観測値

## 何を足したか

`tools/departure-survivability-check.sh` の鎖⑧は RemoteMini **1本だけ**を測っていた。
1本を厳しく測る検査は、**電話に載っている物の総数を一度も数えない**。実際、Tom 本人が
何のアプリか判らない物(`com.tomiees.utsurundesu` / TestFlight 経由 / 持ち主不明)が
2ヶ月以上載っていて、その間ずっと机の上の検査は全部緑だった。

足した物:
- `tools/phone-expected-apps.txt` — 電話に載っているべき物の想定表(req / opt + 覚え書き)
- 鎖⑧に**絞り無しの一覧**(`devicectl device info apps`、`--bundle-id` 無し)との照合
- 三色: req が無い = 赤 / opt が無い = 注記 / 表に無い物が載っている = **注記** /
  表か一覧が読めない = 未測定

**消しはしない。報告だけ**(Tom 2026-08-10「別の AI が作った作成物までは消さないでね」)。
検査が電話から物を消す枝は書いていない。それを機械で見張るのが対照 BR2。

## live の観測(本物の電話・2026-08-10)

```
$ bash tools/departure-survivability-check.sh --days 30
電話の側(この木で署名した RemoteMini が Tom の iPhone に入っているか)
  緑    電話に RemoteMini が入っている(1 件)
  緑    版: 電話 47 = この木 47(ios/ を触った commit の通算数)
  --    同じ番号でも汚れた木で焼いた物は見分けられない —— そこは画面の rev(DESIGN §8-8)の役
  緑    在庫: 電話の 4 本が想定表と一致
```

4 本 = remotemini / blink / deskguard / utsurundesu。`devicectl` の既定の一覧は
**開発者が入れた物だけ**を返す(`--include-all-apps` を付けると 121 本 = App Store 分が
混ざる)。つまり此処が見張るのは「この Mac 経由 / TestFlight で入った物」= 出所を
説明できるべき物だけ。

## 対照 — **赤くなる所を見た**(緑だけの検査は追認機)

対照 12 本を足した(BO / BP / BQ / BR / BR2 / BS / BT / BU / BV / BW / BW2 / BX)。
`test/departure-survivability-controls.sh` は 80 本全部 OK。ただし**全部 OK は証拠に
ならない**ので、対象を8通りに変異させて「狙った対照だけが倒れるか」を測った
(`RC_DEPARTURE_SUT` の継ぎ目を此の為に足した = `prove-control.sh` の対象にもなった)。

基準線: 変異なしの写しを砂場へ置いて回す -> **全部 OK**(砂場そのものは赤の原因ではない)

| 変異(対象をどう壊したか) | 倒れた対照 | 巻き添え |
|---|---|---|
| M1 在庫の照合を丸ごと消す(足す前の版) | BO BP BQ BR BS BT BU BV BW BW2 | 無し |
| M2 表に無い物が載っている -> 注記でなく**赤** | BR | 無し |
| M3 req が消えた -> 赤でなく**注記** | BP | 無し |
| M4 絞り無しが空で返った時の護りを外す | BV(終了 1 = 嘘の赤が出た) | 無し |
| M5 未知のアプリを消しに行く(Tom の禁止を破る) | BR2 | 無し |
| M6 opt が消えた -> 注記でなく**赤** | BQ | 無し |
| M7 想定表の壊れた行を黙って読み飛ばす | BW | 無し |
| M8 空の想定表の護りを外す | BW2 | 無し |
| M9 **出荷している想定表**の行を壊す(対象は無傷) | BX | 無し |

読み方: 各行で倒れたのは狙った対照**だけ**。巻き添えが無い = 名前だけの対照ではなく、
その欠陥を見分けている。M4 と M5 は特に、**嘘の赤**と**消す振る舞い**という
「起きたら気付きにくい方の失敗」を負の側から押さえている。

砂場の作り方の注意(1回踏んだ): 対象を別 dir へ写すと `$HERE` が動くので、
`coldboot-chain.sh` / `ensure-phone-window.sh` / `phone-expected-apps.txt` を一緒に
写さないと**全対照が未測定(2)で汚染**され、変異と無関係な赤が出る。最初の走行で
実際にそうなり、「M2 で BX が倒れた」を変異の効果と読みかけた。基準線の走行を
置いたのはその為。
